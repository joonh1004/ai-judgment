03 / 실험 방법

같은 문장, 다른 비중

배우 연기는 좋았지만
결말은 실망스러웠다

단순 합산: (+2) + (−2) = 0 → 긍정

가중치 적용: (+2 × 0.25) + (−2 × 0.75) = −1 → 부정

0 이상이면 긍정, 0 미만이면 부정

05 / 단어 제거

중요한 단어를 지우면
판단도 달라질까?

배우 연기는 좋았지만 결말은 실망스러웠다.

제거 전: (+2 × 0.25) + (−2 × 0.75) = −1 → 부정

‘실망스러웠다’ 제거 후: +2 × 0.25 = +0.5 → 긍정

남은 단어의 가중치를 유지한다고 가정한 예시

보고서 기록: 30개 중 18개에서 예측 변화 · 60%
